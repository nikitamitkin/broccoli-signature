# Broccoli Group — картинки для email-подписей

Здесь лежит только графика, которую подтягивают HTML-подписи.
Файлы раздаются через GitHub Pages, ссылки на них зашиты в подписи сотрудников —
**не переименовывать и не удалять**, иначе подписи сломаются у всех разом.

- `img-light/` — графика для светлой темы (и для клиентов, которые не умеют выбирать)
- `img-dark/` — графика для тёмной темы

Исходники и сборка подписей — в рабочей папке «84 Брокколи Подписи».
