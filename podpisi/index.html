Куда вставить

Подпись настраивается на компьютере. Вставляйте через Ctrl+V (на Mac — ⌘V), а не «вставить как текст», иначе пропадут картинки и форматирование.

Gmail

  1. Шестерёнка справа вверху → Все настройки.
  2. Вкладка Общие → раздел Подпись → Создать, назовите «Broccoli».
  3. Вставьте подпись в поле справа.
  4. Ниже выберите её в пунктах Для новых писем и Для ответов.
  5. В самом низу страницы — Сохранить изменения.

Яндекс Почта

  1. Шестерёнка на панели слева → Все настройки → Личные данные.
  2. В блоке Ваши подписи вставьте подпись в поле.
  3. Включите Привязать к адресу и выберите свою почту — подпись будет добавляться сама.
  4. Нажмите Добавить подпись.
  5. Внизу страницы в Расположение подписи при ответе выберите вариант, где подпись стоит сразу после вашего ответа, — иначе она уедет под всю переписку.

Outlook — новый и в браузере

  1. Шестерёнка → Учётные записи → Подписи.
  2. Новая подпись, назовите «Broccoli».
  3. Вставьте подпись в поле.
  4. Выберите её для новых сообщений и ответов → Сохранить.

Outlook — классический на Windows

  1. Файл → Параметры → Почта → Подписи.
  2. Создать, назовите «Broccoli».
  3. Вставьте подпись в поле редактирования.
  4. Справа выберите её для новых сообщений и ответов → ОК.

Apple Mail на Mac

  1. Почта → Настройки → Подписи.
  2. Выберите ящик и нажмите +.
  3. Снимите галочку «Всегда использовать мой шрифт по умолчанию».
  4. Вставьте подпись и закройте настройки.

На телефоне почтовые приложения хранят свою, отдельную подпись, и она бывает только текстом. Эта подпись туда не встанет — она работает в письмах, отправленных с компьютера.

Не видно фото или логотипа после вставки? Картинки грузятся из интернета — проверьте соединение и обновите страницу настроек. Если не помогло, скопируйте подпись ещё раз.

Кнопка не копирует? Выделите подпись мышкой целиком и нажмите Ctrl+C.
